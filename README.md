# 🧘‍♀️ **YogiSense – AI-Powered Yoga Pose Correction & Wellness Assistant**

YogiSense is an AI-driven yoga companion that blends **technology + mindfulness** to help users practice yoga with better posture, awareness, and consistency.
It uses **real-time pose detection**, **posture correction**, and a **clean UI** to create a smooth and intelligent wellness experience.
---

## ✨ **What YogiSense Helps You Do**

* Detect incorrect body posture using *real-time keypoint tracking*
* Improve alignment with instant corrective feedback
* Track session duration & number of poses completed
* Monitor accuracy across poses
* View detailed progress analytics
* Enjoy a calm, minimal, user-friendly interface
* Store and review historical yoga sessions
---

# ⭐ **Core Features**

### 🔹 **Real-Time Pose Detection**

* Powered by **MediaPipe** (or PoseNet if you used that)
* Extracts keypoints from your body posture
* Calculates joint angles
* Gives accuracy feedback: **Perfect ✓ / Needs Correction ✧ / Incorrect ✗**
---

### 🔹 **Posture Correction Assistance**

* Highlights incorrectly aligned joints
* Shows visual markers for alignment
* Gives easy-to-understand recommended adjustments
---

### 🔹 **Session Tracking**

* Total yoga session duration
* Number of poses attempted
* Correct vs incorrect posture count
* Automatically generated session summary

---

### 🔹 **User Profiles**

* Personalized user data
* Daily progress monitoring
* Complete history of completed sessions

---

### 🔹 **Analytics Dashboard**

* Weekly progress insights
* Pose accuracy graph
* Streak tracking
* (Optional) Estimated calories burned

---

### 🔹 **Clean & Minimal UI**

* Calm yoga-inspired color palette
* Smooth navigation
* Zero clutter
* Clickable components for a beautiful user experience

---

# 📸 **Additional Features**

* Choose **Beginner**, **Intermediate**, or **Advanced** levels
* Real-time detection of multiple yoga poses
* Aesthetic, clickable UI built for simplicity and beauty
